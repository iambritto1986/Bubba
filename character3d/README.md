# Bubba 3D characters (Oliver & Aria)

Rigged, animated GLB characters for the desktop app, built in Blender 5.2 with MPFB 2 and exported for three.js / React Three Fiber.

## Files

| Path | What |
|---|---|
| `oliver_3d.blend` | Working file: both characters (collections **Bubba** = Oliver, **Aria** = Aria), plus every build script as a Text block |
| `characters_prerig_backup.blend` | Snapshot before rigging |
| `export/oliver.glb`, `export/aria.glb` | Exported characters (also copied to `desktop/public/models/`) |
| `textures/` | Skin, eye, hair and gown/uniform textures generated by the scripts |
| `renders/` | Review renders and animation contact sheets |

## What each GLB contains

- **Skeleton:** Mixamo-compatible (`mixamorig:*` bones, 52), plus `mixamorig:LeftEye` / `mixamorig:RightEye` for look-at. three.js strips the colon, so the names become `mixamorigHead`, `mixamorigLeftEye` and so on. Mixamo clips retarget onto it directly.
- **Clips (30 fps):**
  - Both characters: `idle`, `listening`, `thinking`, `talking`, `cheering`, `walking` (in place, 32-frame cycle), `quirk_wave`, `quirk_shrug`
  - Oliver: `quirk_bow` (hand on heart), `quirk_bowtie` (adjusts bow tie, smooths lapels)
  - Aria: `quirk_greet` (welcoming bow), `quirk_safety_demo` (points to the exits), `quirk_adjust_cap`, `quirk_tuck_hair`
- **Face morph targets:**
  - Eyes and brows: `blink_L`, `blink_R`, `eyeWide`, `squint`, `browUp`, `browDown`, `browInnerUp`, `browUp_L`
  - Expressions: `smile`, `smileOpen`, `frown`, `jawOpen`, `mouthPucker`, `noseScrunch`
  - Mouth shapes: `viseme_aa`, `viseme_E`, `viseme_I`, `viseme_O`, `viseme_U`, `viseme_PP`, `viseme_FF`, `viseme_TH`, `viseme_SS`
- **Body mesh:** only the visible skin is kept (head and neck; for Aria also hands and lower legs), so nothing pokes through the clothes. Eyelashes, teeth and tongue are part of it and move with blinks and mouth shapes.

## How it's used in the app

`src/components/characters/Character3D.tsx` (lazy-loaded from `Bubba.tsx`) layers, every frame:

1. **Body clip** for the state from `useLive()`: cheering, then walking, talking, thinking, listening, else idle. Changes cross-fade over 0.35 s.
2. **Quirks:** a mood change to `oops` plays a shrug; `focus` plays Oliver's bow-tie fix or Aria's safety demo; waking (sleepy to happy) plays the greeting. Idle fidgets play every 16–34 s. Quirks never interrupt talking, listening or thinking. Trigger one from anywhere with `playQuirk("wave" | "greet" | "shrug" | "fidget" | "focus" | "quirk_<clip>")` from `src/lib/quirks.ts`.
3. **Gaze:** the eyes lead and the head follows a beat later, toward the cursor (`useGaze`), up-and-aside while thinking, with occasional idle glances.
4. **Face:** blinks (from `useLive`), a resting expression per mood, and lip-sync from the voice loudness (jaw opens with the level, the mouth shape changes every syllable, the lips close on pauses).

Props: `framing` (`full` / `body` / `bust`; sizes under 130 px default to bust), `walking`, `facing` (radians, for walking across the screen).

To switch back to the 2D characters, set `localStorage.bubba_3d = "0"`. If WebGL fails, the app falls back to 2D automatically.

## Re-exporting after changes (in Blender)

All scripts live in the blend file's Text blocks:

| Script | Purpose |
|---|---|
| `bubba_*` | Oliver's build steps |
| `aria_*` | Aria's build steps |
| `char_pose`, `char_anim` | Pose helpers and the IK hand placement used for animation |
| `oliver_anims`, `aria_anims` | Clip definitions |
| `char_export_body`, `char_export` | Export |

Both characters share clip names, so Blender's actions hold only one character's set at a time. Before exporting a character, run its anims script to regenerate its clips.

To add a Mixamo clip: download it "without skin" as FBX, import it, rename the action (for example `walk_mixamo`), and re-export.

## Known follow-ups

- **Precise lip-sync:** ElevenLabs can return character-level timestamps (the `/with-timestamps` TTS endpoint). Mapping those to the `viseme_*` morphs would beat loudness-based lip-sync for one-off lines.
- **Weight:** each character is about 100–120k triangles and about 5 MB. Decimating the hair clumps would shrink them if performance matters on low-end laptops.
- **Visual cleanup:** Oliver: hair speck and crown gap, flat coat tails. Aria: faint bust points on the jacket, cap sits slightly high, flat pumps.
